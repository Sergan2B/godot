# Sprint 11 External Beta contract vectors

These files are synthetic, model-free contract fixtures. They are not App,
CLI, IDE, package, or human-study evidence and cannot satisfy a qualifying
gate. The acceptance validator requires a `surface_transport_capture` plus a
separate Git-bound external-operator authority for each App/CLI/IDE run, and
`real_human` acquisition records for final evidence.

`contract-vectors.json` drives positive and negative normalization, redaction,
form, revision, and package-path tests. Fixture case results use `match` or
`reject`; they never use the qualifying `passed` status.
